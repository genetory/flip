# Career Launch — 결과물 품질 기준 (Phase 14)

모든 결과물 공통 원칙: 확인된 사실만, 허위 경력·수치·자격 생성 금지, AI 추론↔사실 구분, 목표 직무 연결 근거, 상투어 지양, 초안↔최종 구분, 사용자 최종 확인. **실제 합격 보장 표현 금지.**

## 공통 평가 10항목 (1~5)
사실성 / 직무 적합성 / 구체성 / 개인화 / 구조 / 간결성 / 자연스러움 / 설득력 / 수정 가능성 / 실전 활용성.
**필수 조건**: 허위 사실 0 · 확인 없이 확정된 중요 정보 0 · 결과물 간 사실 불일치 0 · 개인정보 과다노출 0 · 차별/단정 0.
**목표**: 평균 ≥4.0, 사실성 ≥4.7, 직무적합성 ≥4.2, 개인화 ≥4.0, 실전활용성 ≥4.0.

## 통과 기준(결정적, 구현·검증됨)
- 문장별 근거 `SourceLink`(6 검증상태) + `NO_FABRICATION`(unsupported/needsConfirmation).
- **결과물 간 사실 일관성**: `career-artifact-consistency.ts`(구조화 비교, match/paraphrase/needs_confirmation/conflict/unsupported) — **critical(회사·학교·기간·직책·성과수치) 충돌·근거없음 시 최종 확정 차단**(finalizeBlocked). 단위 테스트 10건.
- 버전: `CareerDocumentVersion`(master/targeted·generatedBy ai/user/hybrid) — 사용자 수정 보존, 재생성 시 이전 최종본 유지.
