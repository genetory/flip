# Career Launch — 결과물 평가 시나리오 (Phase 14)

가상 Persona만 사용(실사용자 데이터·결과물 금지). 각 Persona × 결과물 세트 = 직무추천·Career Profile·이력서·자소서·면접질문·평가·오답노트·개선답변·성장리포트.

## Persona별 입력·기대·금지·사실 검증

|---|---|---|---|---|---|
| **A 경험 적은 신입** | 졸업예정·정규경력X·알바+팀프로젝트·수치 적음 | 미확정→코치와 결정 | 알바/수업/프로젝트에서 역량 발굴, 과장 없이 설득 | 없는 경력·수치 생성 | 성과 수치 fabricate 0 |
| **B 프로젝트 多 개발** | 프로젝트 여러개·기술스택 많음·역할/성과 혼재 | 백엔드 | 기여↔팀성과 구분, 목표 직무 관련 우선, 기간/기술/역할 일치 | 기술 나열만, 팀성과=개인 | 결과물 간 기간·기술·역할 일치 |

| **D 외국인 유학생** | 국내취업·한국어 중급·해외+국내 경험·비자 확인 필요 | 마케팅 | 자연스러운 한국어, 해외경험↔역량 연결 | 국적 강조, 비자 단정, 번역체 | 비자 확정 표현 0, IV_SAFETY |
| **E 경력직** | 7년+·성과수치·관리+실무·목표 기업 有 | 프로덕트 리드 | 책임범위·성과 명확, 리더십↔실무 균형 | 신입용 문구 | 성과 수치 출처·의미 유지 |

## 결정적 사실 검증 (LLM 없이)
`checkArtifactConsistency`로 각 Persona의 구조화 사실(목표직무·회사·학교·기간·직책·프로젝트·역할·기술·성과수치·강점·부족역량)을 Career Profile·이력서·자소서·면접에 걸쳐 비교 → 일치/표현만다름/확인필요/충돌/근거없음. **F(충돌)는 critical 충돌 → finalizeBlocked=true** 로 최종 확정 전 확인 강제.

## 모델 콘텐츠 품질 (실행 방법)
실 OpenAI 호출로 각 Persona 결과물 생성 → 공통 10항목 채점. **비용 관리**(Persona/토큰 제한). 실행 불가 시 fixture/mock/schema/prompt 검토로 대체하고 **콘텐츠 품질은 PASS 표기 금지**.
